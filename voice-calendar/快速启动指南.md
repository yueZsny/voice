# 🎤 Voice Calendar — 快速启动指南

## 一、环境要求

- **Node.js** >= 18（你已经装了 v20.19.4 ✅）
- **浏览器** Chrome / Edge（需要麦克风权限）
- **npm** 包管理器

## 二、项目结构

```
voice-calendar/
├── client/                 # 前端 (React + Vite)    → 端口 5173
│   └── src/
│       ├── App.tsx                # 主页面
│       ├── components/            # UI 组件
│       │   ├── Calendar.tsx       # 月视图日历
│       │   ├── RecordButton.tsx   # 录音按钮（点一下开始，再点结束）
│       │   ├── EventList.tsx      # 日程列表
│       │   └── WakeIndicator.tsx  # 唤醒词状态灯
│       └── hooks/                 # 逻辑 hooks
│           ├── useRecorder.ts     # 浏览器录音
│           ├── useWebSocket.ts    # WebSocket 连接
│           └── usePorcupine.ts    # 离线唤醒词（可选）
│
├── server/                 # 后端 (Express + WebSocket) → 端口 3001
│   ├── index.ts                  # 主入口
│   ├── asr.ts                    # 阿里云语音识别
│   ├── llm.ts                    # DeepSeek AI 解析
│   └── db.ts                     # SQLite 数据库
│
├── .env                    # API 密钥配置
├── package.json            # 根项目（一键启动前后端）
└── Voice-Calendar-产品需求文档-v3.md
```

## 三、首次启动（只需做一次）

### 1. 安装依赖

```bash
cd d:\qiniuCloud\voice-calendar

# 安装根依赖
npm install

# 安装前后端依赖
cd server && npm install
cd ..\client && npm install
cd ..
```

### 2. 配置 API 密钥

编辑 `.env` 文件，确认以下三项已填写：

```env
# 阿里云语音识别（ASR）
ALIBABA_CLOUD_ACCESS_KEY_ID=LTAI5t8gtm...    # 你的 AccessKey ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET=tFcKot0OB...   # 你的 AccessKey Secret
ALIBABA_NLS_APP_KEY=gBGGKjMw4I...              # 你的 NLS 项目 AppKey

# DeepSeek AI（LLM 解析）
DEEPSEEK_API_KEY=sk-25e9a52b...                 # 你的 DeepSeek Key
```

| 变量 | 作用 | 不填会怎样 |
|------|------|-----------|
| `ALIBABA_CLOUD_ACCESS_KEY_ID` | 阿里云 API 鉴权 | 使用 Mock 假数据 |
| `ALIBABA_CLOUD_ACCESS_KEY_SECRET` | 阿里云 API 鉴权 | 同上 |
| `ALIBABA_NLS_APP_KEY` | 语音识别项目标识 | 同上 |
| `DEEPSEEK_API_KEY` | AI 解析自然语言 | 使用简易规则解析 |

## 四、启动方式

### 方式一：一键启动（推荐）

```bash
cd d:\qiniuCloud\voice-calendar
npm run dev
```

前后端同时启动：
- 前端 → http://localhost:5173
- 后端 → http://localhost:3001

### 方式二：分别启动

终端 1 — 后端：
```bash
cd d:\qiniuCloud\voice-calendar\server
npm run dev
```

终端 2 — 前端：
```bash
cd d:\qiniuCloud\voice-calendar\client
npm run dev
```

### 启动成功的标志

后端日志应显示：
```
[Server] Voice Calendar API running on http://localhost:3001
[Server] WebSocket ready on ws://localhost:3001
[Server] ASR: 已配置
[Server] LLM: 已配置
```

如果显示「未配置（使用 Mock）」，说明 `.env` 没加载对，回到第四步检查。

## 五、使用方法

1. 浏览器打开 **http://localhost:5173**
2. 看到月视图日历 + 底部录音按钮
3. **点一下**录音按钮（红色脉冲 = 录音中）
4. 对着麦克风说话，例如：**「明天晚上八点和妈妈去吃饭」**
5. **再点一下**结束录音
6. 等待识别 → 日历自动刷新，出现新日程
7. 点击日历上的日期查看当天日程

## 六、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 端口 3001 被占用 | 上次未正常关闭 | 任务管理器结束 node.exe，重新 `npm run dev` |
| 端口 5173 被占用 | 同上 | 同上 |
| 提示「无法访问麦克风」 | 浏览器权限 | Chrome 地址栏左侧 → 网站设置 → 允许麦克风 |
| 识别结果是假数据 | ASR/LLM 没配好 | 检查 `.env` 文件，确认密钥正确 |
| WebSocket 连接失败 | 后端没启动 | 确认 3001 端口有进程在监听 |
| 录音没反应 | 浏览器不支持 | 换 Chrome/Edge |
